
# 📊 SQL Data Warehouse Analytics

## 📌 Project Overview

This project focuses on exploring and analyzing sales, customer,
and product data using SQL to uncover meaningful business insights.

The project demonstrates SQL skills through data exploration,
aggregation, ranking, and time-based analysis.

## 🎯 Project Objectives

- Analyze overall sales performance
- Explore customer and product information
- Identify top-performing products and customers
- Analyze sales trends over time
- Understand revenue distribution across categories
- Practice SQL techniques for business analysis

## 🛠️ Tools & Technologies

- GitHub
- CSV Datasets

## 📊 Dataset Description

The project uses three main datasets:

**Customers:** Customer information and attributes.

**Products:** Product details and categories.

**Sales:** Order transactions, sales amounts, quantities,
and related customer and product information.

## 🔍 SQL Analysis

### 1. Database Exploration
Explore available tables and understand the database structure.

### 2. Dimension Exploration
Analyze customer and product attributes.

### 3. Date Exploration
Examine date ranges and available historical data.

### 4. Measures Exploration
Calculate total sales, total orders, total quantity,
average selling price, and customer counts.

### 5. Magnitude Analysis
Compare sales across product categories and customer groups.

### 6. Ranking Analysis
Identify top-performing products and customers.

### 7. Change Over Time Analysis
Analyze sales trends across different time periods.

## 💡 SQL Concepts Demonstrated

- Aggregate Functions
